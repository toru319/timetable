# ふたりの時間割

公開URL: https://toru319.github.io/timetable/

GitHub Pagesはmainブランチのルートを公開します。依存ライブラリ・ビルド処理は不要です。

## 手元で確認

`npm start` で http://localhost:8000 を開きます。JSONを読み込むため、HTMLファイルの直接オープンではなくHTTPで表示してください。
`npm test` でデータの入力漏れ、予定の重複、参照、単位集計を確認します。

## 学期の更新

1. `data/semesters/` に新学期のJSONを追加し、settings.jsonのsemestersとdefaultSemesterを更新します。
2. coursesに科目の情報を登録します。年度・学期別のファイル内で時間割コードをIDとします。科目名だけで照合しないでください。
3. schedulesのA（玲美）・B（貫）に履修科目の日時を登録します。曜日は月=1〜土=6、時限は1〜6です。時間外はday/periodをnullにします。
4. 同じ科目が複数回ある場合、courseIdを共通にして日時のみ追加します。単位は一度だけ集計されます。不明な単位は0ではなくnullにします。
5. eventsにはSA・サークル・個人の学習予定を登録します。単位には含まれません。学習予定にはcourseIdを付けて詳細に移動できます。
6. 公式シラバスの年度・学期・教室・担当者を照合し、sourceUrl/verifiedAt/sourceStatusに出典を残します。写真上の学習予定と大学指定の時刻は区別してください。
7. テストとスマホ画面の確認後、作業ブランチをコミット・プッシュし、mainへ取り込んで公開処理を確認します。

## ファイル

- index.html / style.css: 画面・表示
- js/app.js: 利用者と学期の選択
- js/timetable.js: 表・科目詳細
- js/data.js: 読み込みと単位集計
- data/: 学期別の科目・履修・予定
- scripts/validate-data.mjs: データ検査

データは公開リポジトリと公開サイトに含まれます。共有範囲を限定する機能はありません。
